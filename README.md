# Choose Your Own Adventure AI (WIP Spring 2026)

A RESTful web API allowing users to interact with an LLM to generate adventures.
Uses a React frontend and a FastAPI backend, connecting to a SQL database (SQLite locally, PostgreSQL remotely) using SQLAlchemy ORM.
